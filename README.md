# C# Vector Console Application

## Description

This is a C#/.NET console application created as an academic project.
The project demonstrates object-oriented programming, working with custom vector data structures, interfaces, arrays, linked lists, streams, and serialization.

The application provides a console menu that allows the user to work with different vector implementations and perform operations on them.

## Features

* Work with `ArrayVector`
* Work with `LinkedListVector`
* Vector addition
* Basic vector operations
* Work with an array of vectors
* Byte stream processing
* Character stream processing
* Serialization
* Console menu navigation

## Project Structure

* `Program.cs` — main application entry point and console menu
* `Vector.cs` — vector logic
* `ArrayVector.cs` — array-based vector implementation
* `LinkListVector.cs` — linked-list vector implementation
* `IVectorable.cs` — interface for vector classes
* `VectorNormComparer.cs` — vector comparison logic
* `App.config` — application configuration file

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/dashazai2025/project_1csharp-json-project.git
   ```

2. Open `ConsoleApp24.sln` in Visual Studio.

3. Build and run the project.

4. Use the console menu to choose an operation.

## Console Menu

The application includes the following menu options:

1. Work with `ArrayVector`
2. Work with `LinkedListVector`
3. Vector addition
4. Vector operations
5. Work with an array of vectors
6. Byte stream
7. Character stream
8. Serialization
